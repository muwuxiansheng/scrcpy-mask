# 压枪配置示例

`m14-727rpm-50rounds-test.json` 保存当前 M14 测试参数：全自动、727发/分钟、50发弹匣，16阶段，总时长4127毫秒，总力度倍率0.5。同指模式，默认关闭。

基础总垂直位移约196.033手机像素，乘倍率后的累计位移约98.016。曲线方向参考用户提供的游戏内改装弹道图；图表没有逐发时序或触摸单位，因此参数仍标记为未校准，不是通用武器预设。更换倍镜、配件、姿态、游戏灵敏度、分辨率或触摸模式后需要重新校准。

在设置页“压枪控制”中点击“导入方案”，选择该JSON，再保存。该示例是只含M14的完整压枪配置，导入会替换方案列表，可先导出原配置保留其他武器。保存后回到控制窗口进入FPS，开启压枪，松开开火再按，新曲线才开始执行。实际弹匣打空或换弹时松开开火；程序没有武器与弹匣识别。

每阶段位移为速度×时长×总倍率，X向右为正、Y向下为正。整体幅度过大可先降低总倍率；只需调整横向或纵向时，修改对应阶段X或Y速度。

原始手机截图、设备信息、日志和第三方配置原文不包含在示例中。
